# Phase 2 Screen Specification

## 目的
MVP の主要画面と補助モーダルの責務を定義し、Phase 3 の UI 実装で画面分割や要素配置の判断が揺れない状態にする。

## 対象範囲
- トップ画面
- シミュレーター画面
- 保存結果画面
- 補助モーダル

## MVP 対象外
- 共有 URL 生成
- 注文フロー接続
- 保存履歴一覧
- アカウント機能
- 高度な比較表示

## 画面一覧

| 画面 ID | 画面名 | 役割 | 主な到達経路 |
|---|---|---|---|
| `home` | トップ画面 | サービス概要を伝え、シミュレーターへ誘導する | 初回訪問 |
| `simulator` | シミュレーター画面 | 画像入力、見え方調整、保存を行う | トップ画面から遷移 |
| `result` | 保存結果画面 | 保存完了と出力画像確認を行う | シミュレーター画面で保存成功 |

## 補助モーダル一覧

| モーダル ID | 用途 | 呼び出し元 | 必須/任意 |
|---|---|---|---|
| `upload` | PNG アップロード手段を提示する | シミュレーター画面 | 必須 |
| `notice` | 実物との差異や注意事項を提示する | トップ画面、シミュレーター画面 | 必須 |
| `save-complete` | 保存成功を即時通知し、次の行動を案内する | シミュレーター画面 | 任意 |

## 画面詳細

### 1. トップ画面

#### 目的
- 初見ユーザーにサービス価値を短時間で伝える
- シミュレーター体験の入口を一本化する
- 実物との差異を先に認知させる

#### レイアウト
- ヘッダー
- ヒーローエリア
- サンプル紹介
- 機能説明
- 注意事項導線

#### 必須 UI 要素
- サービス名
- キャッチコピー
- `試してみる` ボタン
- サンプルビジュアル
- 主要機能の要約
- 注意事項リンク

#### アクション
- `試してみる` でシミュレーター画面へ遷移する
- 注意事項リンクで `notice` モーダルを開く

#### 表示ルール
- ファーストビューで「画像を入れて見え方を確認するサービス」とわかる文言にする
- 補足説明は簡潔にし、詳しい操作説明はシミュレーター画面へ持ち込まない
- 将来機能の説明はしない

### 2. シミュレーター画面

#### 目的
- MVP の中核体験を提供する
- プレビューを主役に、操作パネルを補助として配置する
- 調整から保存までを 1 画面で完結させる

#### レイアウト
- 上部ヘッダー
- 左プレビューエリア
- 右操作パネル
- 保存成功時の補助導線

#### ヘッダー要素
- ロゴまたはサービス名
- 画面タイトル
- トップへ戻る導線
- 注意事項導線

#### プレビューエリア要素
- 3D Canvas
- ローディング表示
- 画像未設定時のプレースホルダー
- エラー表示

#### 操作パネル要素
- 画像設定
- 発光設定
- 表示設定
- 出力設定

#### セクション詳細

##### 画像設定
- PNG アップロードボタン
- 選択中ファイル名
- 差し替え導線
- 失敗時の再試行案内

##### 発光設定
- LED 色プリセット
- 明るさスライダー

##### 表示設定
- 背景プリセット
- カメラプリセット切替
- カメラリセット
- 設定リセット

##### 出力設定
- 画像保存ボタン
- 保存状態メッセージ

#### アクション
- PNG を選択するとプレビューへ即時反映する
- LED 色や明るさを変更すると Canvas 表示が更新される
- 背景やカメラを切り替えて複数条件を比較する
- 保存成功時は保存結果画面または保存完了モーダルへ遷移する

#### 状態別 UI

| 状態 | 表示内容 |
|---|---|
| 初期 | サンプル表示または未設定プレースホルダー、操作案内 |
| 画像読込中 | ローディング表示、操作の一部を待機表示 |
| 読込成功 | ファイル名と現在設定を表示 |
| 読込失敗 | エラーメッセージと再試行導線を表示 |
| 保存中 | 保存ボタンを処理中表示にする |
| 保存成功 | 保存完了メッセージと結果確認導線を表示 |
| 保存失敗 | エラーメッセージと再保存導線を表示 |

### 3. 保存結果画面

#### 目的
- 保存成功を明示する
- 出力画像を確認させる
- 再編集か新規作成かの次アクションを案内する

#### 必須 UI 要素
- 保存完了メッセージ
- 出力画像プレビュー
- 再編集ボタン
- 新規作成ボタン
- ダウンロードボタン

#### アクション
- 再編集でシミュレーター画面へ戻る
- 新規作成で状態を初期化してシミュレーター画面へ戻る
- ダウンロードで生成済み画像を保存する

#### 表示ルール
- 直前に保存した画像と主要設定値が識別できること
- 共有や注文導線はプレースホルダー説明のみで UI 化しない

## モーダル仕様

### `upload`
- 用途: ファイル選択またはドラッグ&ドロップを促す
- 入力制約: PNG のみ、推奨サイズを明記する
- 異常系: 非 PNG 選択時に即時エラー表示する

### `notice`
- 用途: 実物との差異、LED や素材差による変動を伝える
- 表示タイミング: 初回導線とヘッダー導線から任意表示

### `save-complete`
- 用途: シミュレーター画面から離れず保存成功を伝える
- 表示内容: 保存完了、結果を見る、続けて編集する

## レスポンシブ方針
- デスクトップ優先で設計する
- タブレット以下ではプレビューを上、操作パネルを下へ積む
- スマートフォンでは閲覧優先とし、保存操作は維持するが細かな比較 UI は載せない

## 実装メモ
- 現行 `app/page.tsx` の PoC レイアウトは、トップ画面とシミュレーター画面の責務が混在している
- Phase 3 では `app/page.tsx` をトップ画面、`app/simulator/page.tsx` をシミュレーター画面、`app/result/page.tsx` を保存結果画面へ分離する
- シミュレーター画面のプレビューエリアは `SimulatorCanvas`、操作パネルは専用コンポーネントへ責務分離する
