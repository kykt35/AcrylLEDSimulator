# 画面構成案
## プロジェクト名
LEDアクリルスタンド見え方シミュレーター（Web版）

---

## 1. 画面構成の基本方針

本システムの画面構成は、以下の方針で設計する。

- 初見でも使い方がわかる
- まずは「画像を入れて見え方を確認する」ことに集中できる
- UIよりプレビューを主役にする
- MVPでは画面数を増やしすぎない
- 将来の保存・共有・注文導線を追加しやすい構成にする

---

## 2. MVPの画面一覧

MVPでは以下の3画面構成を基本とする。

1. トップ / ランディング画面
2. シミュレーター画面
3. 完了 / 保存結果画面

必要に応じて、モーダルとして補助UIを追加する。

- 画像アップロードモーダル
- 注意事項モーダル
- 保存完了モーダル

---

## 3. 画面一覧詳細

---

## 3.1 トップ / ランディング画面

### 目的
- サービス概要を伝える
- ユーザーをシミュレーターへ誘導する
- 何ができるかを一目で理解させる

### 想定ユーザー
- 初めて訪問するユーザー
- 商品ページやLPから流入したユーザー

### 主な要素
- サービス名
- キャッチコピー
- メインビジュアル
- シミュレーターでできることの説明
- サンプル画像
- 「試してみる」ボタン
- 注意事項への導線

### 主要アクション
- シミュレーター開始
- サンプルを見る
- 注意事項を確認する

### ワイヤーイメージ
```text
+--------------------------------------------------+
| ロゴ / サービス名                               |
+--------------------------------------------------+
| キャッチコピー                                  |
| 「LEDアクスタの完成イメージをブラウザで確認」   |
| [試してみる]                                    |
+--------------------------------------------------+
| サンプルプレビュー画像                           |
+--------------------------------------------------+
| できること                                       |
| - 画像アップロード                              |
| - LED色変更                                     |
| - 背景切替                                      |
| - 保存                                           |
+--------------------------------------------------+
| 注意事項リンク                                   |
+--------------------------------------------------+
```

## 3.2 シミュレーター画面

#### 目的
- メイン機能を提供する中核画面
- 画像をアップロードして見え方を確認する
- 設定を変えながら比較する
- 保存する

#### 基本レイアウト
- 左: プレビューエリア
- 右: 操作パネル
- 上: ヘッダー
- 下または右下: 補助アクション

#### 画面構成
##### ヘッダー
- ロゴ
- 画面タイトル
- トップへ戻る
- 注意事項
- 将来用の保存 / 共有導線

##### 左ペイン（3Dプレビュー）
- アクリルスタンド表示
- 台座表示
- 背景表示
- カメラ操作対象
- ローディング表示
- エラー表示

##### 右ペイン（操作パネル）
- 画像アップロード
- LED色変更
- 明るさ調整
- 背景切替
- カメラリセット
- 設定リセット
- 保存ボタン

##### セクション分け（操作パネル）
- A. 画像設定
  - 画像アップロードボタン
  - 画像差し替え
  - アップロード状態表示
- B. 発光設定
  - LED色選択
  - 明るさスライダー
- C. 表示設定
  - 背景色切替
  - カメラ視点リセット
  - 自動回転（将来候補）
- D. 出力
  - 保存
  - 比較用複製（将来候補）
  - 共有（将来候補）

#### ワイヤーイメージ
```text
+----------------------------------------------------------------------------------+
| ロゴ | 画面タイトル | トップへ戻る | 注意事項                                   |
+----------------------------------------------------------------------------------+
|                                      |                                           |
|                                      | 画像設定                                  |
|                                      | [画像をアップロード]                      |
|                                      | アップロード済みファイル名                |
|                                      |                                           |
|                                      | 発光設定                                  |
|          3Dプレビュー                 | LED色 [○ ○ ○ ○ ○]                        |
|                                      | 明るさ [------●----]                      |
|                                      |                                           |
|                                      | 表示設定                                  |
|                                      | 背景 [白][黒][グレー]                    |
|                                      | [カメラリセット]                          |
|                                      | [設定リセット]                            |
|                                      |                                           |
|                                      | 出力                                      |
|                                      | [画像を保存]                              |
|                                      |                                           |
+----------------------------------------------------------------------------------+
```

## 3.3 完了 / 保存結果画面

#### 目的
- 保存完了を明確に伝える
- 出力画像を確認させる
- 再編集や再保存へ戻しやすくする
- 将来的に共有や注文へつなげる

#### 主な要素
- 保存完了メッセージ
- 保存画像のプレビュー
- 再編集ボタン
- 新規作成ボタン
- ダウンロードボタン
- 共有導線（将来候補）
- 注文へ進む（将来候補）

#### ワイヤーイメージ
```text
+--------------------------------------------------+
| 保存が完了しました                               |
+--------------------------------------------------+
| 出力画像プレビュー                               |
|                                                  |
+--------------------------------------------------+
| [再編集する]  [新しく作る]  [ダウンロード]       |
+--------------------------------------------------+
| 将来候補: [共有する] [注文へ進む]                |
+--------------------------------------------------+
```
## 4. モーダル構成案

### 4.1 画像アップロードモーダル

#### 用途
- ドラッグ&ドロップ
- ファイル選択

#### 表示内容
- 「PNGをアップロードしてください」

#### 補足
- 対応形式の説明
- 対応形式
- 推奨画像サイズ
- [ファイルを選択]
- [キャンセル]

### 4.2 注意事項モーダル

#### 用途
- 実物との差異説明
- 期待値調整

#### 表示内容
- 本シミュレーターは完成イメージです
- 実物とは見え方が異なる場合があります
- LED色や素材差により印象が変わる場合があります

### 4.3 保存完了モーダル

#### 用途
- シミュレーター画面上で保存完了を即時通知する

#### 表示内容
- 保存完了
- [画像を確認]
- [続けて編集]
- [閉じる]

## 5. 画面遷移案
#### 遷移図
```text
トップ画面
  ↓
シミュレーター画面
  ├─ 画像アップロードモーダル
  ├─ 注意事項モーダル
  ├─ 保存完了モーダル
  ↓
保存結果画面
  ├─ 再編集
  └─ 新規作成
```

#### 遷移の考え方
- 基本導線はシンプルにする
- ユーザーが迷わないように分岐を増やしすぎない
- 主要操作はシミュレーター画面内で完結させる

## 7. MVPで重視するUI要件

### 7.1 分かりやすさ
- 最初に何をすればよいか一目で分かる
- 「画像を入れる → 色を変える → 保存する」が自然に進む

### 7.2 プレビュー重視
- 画面の主役はプレビュー
- 設定UIが主張しすぎない

### 7.3 操作の軽さ
- 設定変更がすぐ反映される
- 迷う設定項目を増やしすぎない

### 7.4 期待値調整
- 実物との差異があることを適切に伝える

## 9. 推奨するMVP画面構成の最終案

#### MVPで実装する画面
- トップ / ランディング画面
- シミュレーター画面
- 保存結果画面

#### MVPで実装するモーダル
- 画像アップロードモーダル
- 注意事項モーダル
- 保存完了モーダル

#### この構成の利点
- シンプルで迷いにくい
- 実装量を抑えやすい
- 価値検証に必要十分
- 将来の共有・注文・管理機能を追加しやすい

## 10. 一言でまとめると
「トップで始めて、シミュレーターで確認し、保存結果で締める」シンプルな3画面構成がMVPには最適
