# MVP UI Design

## 目的

現行の1画面シミュレーターを基準に、プレビュー、設定パネル、通知、レスポンシブ表示の構成を定義する。

## 基本方針

- 最初に行う操作がPNG追加だと分かる
- 画像入力、見え方の調整、ダウンロードを1画面で完結させる
- 3Dプレビューを画面の主役にする
- 設定UIは画像読込後にだけ表示し、必要なタブを開いたときだけ展開する
- ローカル出力は「保存」ではなく「ダウンロード」と表現する
- 成功・失敗で画面遷移せず、現在の編集状態を維持する

## 画面構成

`/` と `/simulator` はどちらも次の構成を持つ。

```text
+------------------------------------------------------------------+
| LEDアクスタ シミュレーター   使い方 | このアプリについて | 注意事項 |
+------------------------------------------------------------------+
| [ライト] [カメラ] [配置] [彫刻] [書出し]  [書出範囲] [リセット] |
|                                                                  |
|                         3Dプレビュー                             |
|                                                                  |
|                     ┌────────────────────┐                       |
|                     | 選択中タブの設定   |                       |
|                     └────────────────────┘                       |
+------------------------------------------------------------------+
| エラー表示（発生時）                                             |
+------------------------------------------------------------------+
                                                   [成功toast]
```

初期状態では設定タブ行を表示せず、3Dプレビュー領域にPNG追加の案内を表示する。

## ヘッダー

### デスクトップ

- 左側に画面タイトルと「画像の読み込み、見え方の調整、ダウンロードまでを1画面で進めます。」という説明を置く
- 右側に使い方、このアプリについて、注意事項を置く

### モバイル

- 補助導線をハンバーガーメニューへ格納する
- メニュー外押下またはEscapeで閉じる
- 注意事項を開く前にメニューを閉じる

## 初期状態と画像入力

- 3Dビュー領域全体をファイル選択の入口にする
- 「PNGファイルを追加して始めましょう」と操作説明を表示する
- ドラッグ中は「ここにドロップして画像を差し替え」とPNG対応を表示する
- 画像読込中はスピナーと進行メッセージを重ねる
- 非PNG、8MB超過、読込失敗はプレビュー下のエラーで通知する

専用の画像アップロードモーダルやサーバーアップロード進捗は設けない。

## 3Dプレビューと設定

### 設定タブ

- 順序は `ライト`、`カメラ`、`配置`、`彫刻`、`書出し`
- 各タブは操作内容を示すラベルを持つ
- 選択状態と処理の進行状態を属性と見た目で区別する
- キーボードの矢印、Home、Endで移動できる

### 設定パネル

- 選択中タブの内容だけを3Dビュー上へ表示する
- 同じタブ、Escape、3Dビュー押下で閉じる
- パネル内操作は3Dビューへのクリックとして扱わない
- 入力値の変更を3Dプレビューへ即時反映する

### 書出範囲

- 設定タブとは独立したトグルで表示する
- 範囲全体の移動と四隅のリサイズを提供する
- オーバーレイ操作中はカメラ操作との競合を避ける

## 書出しUI

- 書出しタブにクロップ済みプレビューを表示する
- PNG/JPGはradio相当のセグメントで切り替える
- 主操作の文言は「画像をダウンロードする」とする
- 画像未選択時または処理中はダウンロード操作を無効にする
- 処理中は「ダウンロード中...」と表示する

彫刻用PNGのダウンロードは彫刻タブ内に置き、シミュレーション画像のPNG/JPGダウンロードと区別する。

## フィードバック

### 成功toast

```text
+--------------------------------------------------+
| ✓ Download Ready                                |
|   ダウンロードを開始しました                   |
|   現在の見え方を PNG/JPG として出力しました。  |
|   このまま続けて調整できます。          [閉じる] |
+--------------------------------------------------+
```

- `role="status"` とライブリージョンで非割り込み通知として扱う
- 結果画面へのリンクや「新しく作る」操作は置かない
- 閉じた後も画像、設定、書出範囲を維持する

### エラー

- 画像読込、彫刻生成、ダウンロードのエラーは `ErrorNotice` で表示する
- メッセージは失敗した操作と再試行可能であることが分かる文言にする
- エラー発生だけを理由に画面を移動または初期化しない

### 処理中

- 画像読込、彫刻生成、ダウンロードはプレビュー上のローディング表示を共用する
- 状態を視覚表示だけでなくライブリージョンでも通知する

## 注意事項dialog

- 画面上の見え方が実物保証ではないことを伝える
- 閉じるボタン、Escape、背景押下で閉じられる
- dialog表示中は背景スクロールとdialog外へのフォーカス移動を防ぐ
- 表示幅が変わってもdialogを維持し、閉じた時点で可視なトリガーへフォーカスを戻す

## レスポンシブ方針

### 961px以上

- ヘッダーの補助導線を横並びで表示する
- 3Dプレビューを広く確保し、設定パネルをプレビュー内へ重ねる

### 960px以下

- ヘッダーの補助導線をハンバーガーメニューへ切り替える
- 設定タブを利用可能なまま保ち、パネルを画面幅へ収める
- 成功toastを左右の余白内へ収める
- PNG入力、調整、ダウンロードの全主操作を省略しない

## アクセシビリティ

- 設定タブは `tablist`、`tab`、`tabpanel` の関係を持つ
- 選択状態と開閉状態を `aria-selected`、`aria-expanded` で伝える
- 空のプレビュー面はキーボード操作可能なbutton相当として扱う
- ローディング、成功、エラーは適切なライブリージョンまたはroleで通知する
- dialogはフォーカストラップとトリガーへのフォーカス復帰を持つ

## 将来候補

- 保存結果専用画面と結果画像の再表示
- サーバー永続化、共有URL、保存履歴
- 複数結果の比較
- 注文、管理画面

将来候補を追加する場合も、現行のローカルダウンロードを置き換えるのか併存させるのかを先に決定する。
