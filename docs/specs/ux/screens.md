# MVP Screen Specification

## 目的

現行MVPの画面と補助UIの責務を定義し、実装されていない結果画面やアップロードモーダルを現行要件と混在させない。

## MVP画面一覧

| 画面ID | URL | 役割 | 主な到達経路 |
|---|---|---|---|
| `simulator-root` | `/` | 画像入力、調整、彫刻画像生成、ダウンロードを1画面で行う | 初回訪問、補助ページから戻る |
| `simulator-alias` | `/simulator` | `/` と同じ `SimulatorScreen` を表示する | 直接アクセス |
| `usage` | `/usage` | 基本操作を説明する | シミュレーターヘッダー |
| `about` | `/about` | アプリの目的と機能を説明する | シミュレーターヘッダー |

`/` と `/simulator` の表示内容と機能は同じであり、トップ画面からシミュレーター画面へ進む段階は設けない。

## 補助UI一覧

| UI ID | 種別 | 用途 | 呼び出し元 |
|---|---|---|---|
| `notice` | dialog | 実物との差異や利用上の注意事項を表示する | ヘッダー、about、usage |
| `save-complete` | status toast | PNG/JPGのダウンロード開始を通知する | シミュレーター画面 |
| `control-drawer` | panel | ライト、カメラ、配置、彫刻、書出し設定を表示する | 画像読込後の設定タブ |

画像入力は3Dビューへ統合されており、専用アップロードモーダルは使用しない。

## シミュレーター画面

### 目的

- PNGの入力からシミュレーション画像のダウンロードまでを1画面で完結させる
- 3Dプレビューを主役にし、設定を必要なときだけ表示する
- 成功・失敗後も編集状態を保持して操作を続けられるようにする

### レイアウト

- 上部: 画面タイトル、説明、使い方、アプリ概要、注意事項
- 中央: 3DプレビューまたはPNG追加を促す空状態
- 画像読込後のプレビュー上部: 設定タブ、書出範囲トグル、リセット
- 設定タブ選択中: 3Dビュー上へ重なる設定パネル
- ダウンロード成功時: 画面右下の成功toast

### 初期状態

- 「PNGファイルを追加して始めましょう」と表示する
- 3Dビュー領域のクリック、Enter、Spaceでファイル選択を開く
- PNGをドラッグ中はドロップ位置を示すオーバーレイを表示する
- 設定タブ、リセット、ダウンロード操作は表示しない

### 画像読込後

- 3D Canvasへ画像を表示する
- プレビュー上部に `ライト`、`カメラ`、`配置`、`彫刻`、`書出し` タブを表示する
- 読込済みの3DビューへPNGをドロップすると画像を差し替える
- リセットで画像、調整値、UI状態、保存済みスナップショットを初期化する

### 設定パネル

| タブ | 主な操作 |
|---|---|
| ライト | LED色、明るさ、高さ方向の減衰 |
| カメラ | 背景、カメラプリセット、元画像オーバーレイ、カメラリセット |
| 配置 | アクリルサイズ、content fit、画像サイズ、縦横位置 |
| 彫刻 | 彫刻モード、階調/グレースケール、彫刻調整、彫刻用PNGダウンロード |
| 書出し | クロップ済みプレビュー、PNG/JPG選択、シミュレーション画像ダウンロード |

- 同じタブを再度押すと設定パネルを閉じる
- 別タブを押すと内容を切り替える
- Escapeまたは3Dビュー押下で閉じる
- 矢印キー、Home、Endでタブを移動できる

### 書出範囲

- 初期状態では非表示
- トグルで表示し、範囲の移動と四隅のリサイズを行う
- 表示中は3Dビューのカメラ操作を抑止する
- 書出しタブ内に現在範囲のプレビューを表示する

### ダウンロード

- 元画像がある場合だけ「画像をダウンロードする」を有効にする
- 実行中は「ダウンロード中...」と表示して二重実行を防ぐ
- 成功時は結果画面へ遷移せず、成功toastを表示する
- toastにはダウンロード開始、出力形式、継続編集できること、閉じる操作を表示する
- 失敗時はプレビュー下部へ `ErrorNotice` を表示し、画像と設定を保持する

### 状態別UI

| 状態 | 表示内容 |
|---|---|
| 初期 | PNG追加を促す空状態 |
| 画像読込中 | プレビュー上のローディング表示 |
| 読込成功 | 3D Canvas、設定タブ、書出範囲トグル、リセット |
| 読込失敗 | 画像読込エラーと再選択可能な空状態 |
| 彫刻生成中 | プレビュー上のローディング表示 |
| 彫刻生成失敗 | 彫刻生成エラー |
| ダウンロード中 | ローディング表示と無効化されたダウンロードボタン |
| ダウンロード成功 | 成功toast。画面と編集状態は維持 |
| ダウンロード失敗 | ダウンロードエラー。画面と編集状態は維持 |

## ヘッダーと補助ページ

- 961px以上では、使い方、このアプリについて、注意事項をヘッダーへ表示する
- 960px以下では同じ項目をハンバーガーメニューへ格納する
- 注意事項はdialogで表示し、閉じるボタン、Escape、背景押下で閉じる
- dialog表示中はフォーカスを内部に保ち、閉じた後は表示幅に応じて可視なトリガーへ戻す
- `/usage` と `/about` は `/` へ戻る導線を持つ

## レスポンシブ方針

- デスクトップではプレビューを広く保ち、設定パネルを3Dビュー上に表示する
- 960px以下でもPNG入力、全設定タブ、書出範囲、ダウンロードを利用できる
- 成功toastは小さい画面で左右の余白に収まり、本文や閉じる操作を欠落させない
- モバイルメニューと注意事項dialogは同時に開いた状態にしない
