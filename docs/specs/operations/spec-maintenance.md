# 仕様更新ルール

## 目的

実装と仕様ドキュメントのずれを小さく保ち、開発時に参照すべき仕様を判断できる状態を維持する。

## 基本方針

- 実装の振る舞いが変わる変更では、同じPRまたは同じ作業単位で仕様も更新する。
- `feature-index.md` は一覧とリンクだけを持つ。機能の詳細は `features/*.md` へ書く。
- 仕様に影響しない内部リファクタ、テスト追加、軽微な文言修正では、仕様更新は不要でよい。
- 実装から意図を断定できない内容は、詳細仕様の `未確認・推定` に残す。
- 実装と仕様が矛盾している場合は、実装を直すのか仕様を直すのかを明示してから変更する。

## 更新が必要な変更

| 変更内容 | 更新先 |
|---|---|
| 新機能を追加する | `feature-index.md` に行を追加し、該当する詳細仕様を作成/更新する |
| 既存機能のUI挙動を変える | 該当する `features/*.md` と必要に応じて `ux/screens.md` を更新する |
| 画像入力、ファイル制限、バリデーションを変える | `features/image-input.md` と `architecture/error-handling.md` を更新する |
| 彫刻マップ生成ロジック、調整項目、初期値を変える | `features/engraving-map.md` を更新する |
| LED色、明るさ、減衰、プリセットを変える | `features/lighting-controls.md` を更新する |
| 背景、カメラ、アクリルサイズ、3D表示を変える | `features/display-controls.md` と必要に応じて `architecture/component-design.md` を更新する |
| 書き出し形式、ファイル名、クロップ、保存/復元を変える | `features/export-save.md` と `architecture/data-model.md` を更新する |
| APIの入口、パラメータ、レスポンス、エラーを変える | `architecture/api.md` と該当する詳細仕様を更新する |
| 状態モデルを変える | `architecture/state-design.md` と該当する詳細仕様を更新する |
| 機能名、カテゴリ、詳細仕様ファイル名を変える | `feature-index.md` のリンクを更新する |

## 更新しなくてよい変更

| 変更内容 | 条件 |
|---|---|
| 内部リファクタ | 外部仕様、状態、保存データ、エラー、書き出し結果に影響しない |
| テスト追加のみ | 実装仕様に変更がない |
| コメントやログの修正 | ユーザーが見る挙動に影響しない |
| 表示文言の微修正 | 意味や操作フローが変わらない |
| スタイル調整 | レイアウト、操作可否、表示内容の意味が変わらない |

## 作業手順

1. `feature-index.md` で対象機能と詳細仕様を確認する。
2. 変更したコードから、入口、状態、エラー、保存データ、関連実装、関連テストを確認する。
3. 該当する詳細仕様を更新する。
4. 新しい機能やカテゴリが増えた場合だけ、`feature-index.md` を更新する。
5. 仕様判断が必要な点は、詳細仕様の `未確認・推定` に残す。
6. PRや作業報告で、仕様更新の有無を明記する。

## 詳細仕様の見出し

詳細仕様は、原則として以下の見出しを使う。

```md
# 機能名

## 目的
## 利用者
## 入口
## 実装から分かる仕様
## エラー・例外
## 関連実装
## 関連テスト
## 未確認・推定
```

必要がある場合だけ、`主な状態` や `データ` などの見出しを追加する。

## PR前チェック

- 仕様に影響する変更か確認した。
- 影響する場合、該当する詳細仕様を更新した。
- 新機能の場合、`feature-index.md` に行を追加した。
- API、状態、保存/復元、書き出し、エラーの変更が仕様に反映されている。
- 未確認事項を `未確認・推定` に残した。
- 関連実装と関連テストの記載が古くなっていない。

## 判断例

| 実装変更 | 仕様更新 |
|---|---|
| PNGの最大サイズを変更 | `features/image-input.md` を更新 |
| 彫刻調整に新しいスライダーを追加 | `features/engraving-map.md` を更新 |
| LED色プリセットを追加 | `features/lighting-controls.md` を更新 |
| カメラプリセットを変更 | `features/display-controls.md` を更新 |
| JPG書き出しを廃止 | `features/export-save.md` と `feature-index.md` を更新 |
| コンポーネント名だけを変更 | 関連実装の記載がある詳細仕様だけ更新 |
