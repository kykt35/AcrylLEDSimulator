# MVP Acceptance Criteria

## 目的

現行の1画面シミュレーターについて、MVP実装完了とQAの判定基準を定義する。

## 対象範囲

- PNGファイル選択、ドラッグ&ドロップ、差し替え
- 3Dプレビューと彫刻用画像生成
- ライト、背景、カメラ、配置、アクリルサイズ、彫刻調整
- 書出範囲とPNG/JPGダウンロード
- 彫刻用PNGダウンロード
- 成功toast、エラー回復
- セッション保存、復元、初期化
- デスクトップ、モバイルの主要導線

## 受入基準

### 1. 1画面導線

- `/` と `/simulator` は同じ `SimulatorScreen` を表示する
- PNG追加からシミュレーション画像のダウンロードまで、結果画面へ遷移せず完了できる
- `/usage` と `/about` から `/` へ戻れる
- MVPの主導線に `/result`、`/api/save`、サーバー保存を要求しない

### 2. 画像入力

- PNGを選択またはドロップすると、FileReaderで読み込み3Dプレビューへ反映する
- 読込済みの3Dビューへ別のPNGをドロップすると差し替えられる
- PNG以外、8MB超過、読込失敗で再選択可能なエラーを表示する
- 画像入力時にサーバーAPIを呼び出さない

### 3. プレビューと調整

- アクリル板、LED台座、入力画像または彫刻画像を3D表示する
- ライト、背景、カメラ、配置、アクリルサイズ、彫刻設定の変更をプレビューへ反映する
- 設定タブをマウスとキーボードで開閉、切替できる
- WebGLエラーまたはcontext lost時に復旧導線を表示する

### 4. シミュレーション画像のダウンロード

- 画像読込後に書出しタブからPNGまたはJPGを選択できる
- 書出範囲を移動またはリサイズし、クロップ済みプレビューを確認できる
- ダウンロード操作で現在のCanvasを選択形式のBlobへ変換し、元ファイル名を基にしたファイル名で開始する
- 処理中は二重実行を防ぐ
- 成功時は画面遷移せず成功toastを表示する
- toastに出力形式、ダウンロード開始、継続編集できることを表示する
- toastを閉じても画像と設定を保持し、調整や再ダウンロードを続けられる

### 5. 彫刻用PNGのダウンロード

- 彫刻用画像の生成後に彫刻タブからPNGをダウンロードできる
- 元ファイル名に `-engraving.png` を付けたファイル名を使う
- 白黒反転の選択をダウンロード結果へ反映する

### 6. セッション保存・復元

- シミュレーション画像のBlob生成後、編集状態を `sessionStorage` へ保存する
- `?resume=1` で元画像、彫刻、ライト、背景、カメラ、配置、アクリルサイズを復元する
- 不足している互換対象値は既定値または許容範囲へ補正する
- `sessionStorage` が利用できない場合はメモリへフォールバックする
- `?reset=1` または画面上のリセットで画面状態と保存済みスナップショットを初期化する

### 7. エラー時挙動

- 画像読込、彫刻生成、Canvas書き出しの失敗を画面内に表示する
- ダウンロード失敗時も現在の画像と設定を保持する
- 失敗後に設定変更または再試行できる
- エラーを理由に結果画面へ遷移しない

## 非機能基準

### 対応環境

- Chrome最新版
- Edge最新版
- Safari最新版
- デスクトップを優先しつつ、960px以下でも主要操作を維持する

### アクセシビリティ

- 画像未選択時のプレビュー面をEnterまたはSpaceで操作できる
- 設定タブを矢印、Home、Endで移動し、Escapeで閉じられる
- 処理中、成功、エラーをライブリージョンまたは適切なroleで通知する
- 注意事項dialogでフォーカスを管理し、閉じた後に可視なトリガーへ戻す

## MVP対象外

- 保存結果専用画面
- サーバーへの画像・シミュレーション永続化
- 共有URL
- 保存履歴、比較保存
- 注文導線
- 本格的なアカウント管理
- 光学的に厳密な再現

## QAチェック観点

| 観点 | 確認内容 |
|---|---|
| 基本導線 | PNG追加から調整、ダウンロード、継続編集までを1画面で完了できる |
| 入力制約 | 非PNG、8MB超過、壊れた画像で異常終了しない |
| 見た目 | デスクトップと960px以下で主要UIと3D表示が重ならず操作できる |
| ダウンロード | PNG/JPG、クロップ、彫刻用PNG、白黒反転が期待どおり出力される |
| 通知 | 成功toastと失敗メッセージが状態と次の行動を伝える |
| 回復性 | エラー後の再試行、`resume`、`reset` が機能する |
| データ境界 | MVPの処理がブラウザ内で完結し、サーバー保存APIへ依存しない |
