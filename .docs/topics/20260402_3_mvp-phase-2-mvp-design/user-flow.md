# Phase 2 User Flow

## 目的
初回訪問から保存完了までの主要導線と分岐条件を明示し、画面仕様、状態設計、受入基準の共通入力とする。

## 主導線

```text
トップ画面
  ↓ 試してみる
シミュレーター画面
  ↓ PNG アップロード
プレビュー確認
  ↓ LED 色 / 明るさ / 背景 / カメラ調整
保存実行
  ↓ 成功
保存結果画面
```

## ユースケース別フロー

### 1. 初回訪問ユーザーが完成イメージを確認する

1. ユーザーがトップ画面へ到達する
2. サービス概要と注意事項を確認する
3. `試してみる` を押してシミュレーター画面へ進む
4. PNG をアップロードする
5. 3D プレビューを確認する
6. LED 色、明るさ、背景、カメラを調整する
7. 現在の見え方を保存する
8. 保存結果画面で出力画像を確認する
9. 必要に応じて再編集または新規作成へ進む

### 2. 既存画像を差し替えて比較する

1. シミュレーター画面で既存画像を読み込み済みの状態から開始する
2. 画像差し替えを選択する
3. 新しい PNG を選択する
4. 読み込み成功後、プレビューが差し替わる
5. 前回設定を維持したまま比較する
6. 必要に応じて保存する

### 3. 保存失敗から復帰する

1. ユーザーがシミュレーター画面で保存を実行する
2. 保存処理で失敗する
3. UI に失敗理由と再試行導線を表示する
4. ユーザーが再保存または設定変更を行う
5. 保存成功後に保存結果画面へ進む

## 主要分岐

### 分岐 A: アップロード前
- 画像未選択時はプレースホルダー表示とアップロード案内を優先する
- 保存ボタンは無効化または説明付き待機状態にする

### 分岐 B: アップロード失敗
- 非 PNG または読み込み失敗時はエラーメッセージを表示する
- 直前の有効な画像がある場合は表示を維持する
- 有効画像がない場合は未設定状態へ戻す

### 分岐 C: 調整中
- LED 色、明るさ、背景、カメラ変更は即時プレビューへ反映する
- 調整中に保存可能条件を満たしていれば保存を許可する

### 分岐 D: 保存成功
- 保存結果画面へ遷移するか、保存完了モーダルを表示してから遷移する
- 保存済み画像データと表示用メタデータを次画面へ渡す

### 分岐 E: 保存失敗
- 現在のプレビュー状態は失わない
- 再試行導線と失敗理由を残す
- 重大エラーでない限り画面遷移は行わない

## 画面遷移条件

| From | To | 条件 |
|---|---|---|
| トップ画面 | シミュレーター画面 | `試してみる` を押下 |
| シミュレーター画面 | 保存結果画面 | 保存処理成功 |
| 保存結果画面 | シミュレーター画面 | `再編集` または `新規作成` を押下 |
| 任意画面 | 注意事項モーダル | 注意事項導線を押下 |

## データ受け渡し

| 区間 | 受け渡し内容 |
|---|---|
| トップ画面 → シミュレーター画面 | 初期導線情報のみ。入力データは持たない |
| シミュレーター画面内 | 画像 URL、ファイル名、発光設定、背景設定、カメラ設定、保存状態 |
| シミュレーター画面 → 保存結果画面 | 出力画像、主要設定値、再編集用のシミュレーション設定 |

## UX ルール
- 主導線は常に 1 本に保ち、サブ導線はモーダルか小さな補助アクションに限定する
- シミュレーター画面では「アップロード」「調整」「保存」の順番が自然に読める構成にする
- エラー時はユーザーの現在設定を極力保持する
- 保存成功後は必ず次アクションを提示する

## Phase 3 への引き継ぎ事項
- ナビゲーションよりも画面内完結を優先する
- 保存結果画面の実装が重い場合は、初期版ではシミュレーター画面上の保存完了モーダルで代替可能とする
- 比較表示や共有導線は Phase 3 の初回スコープから除外し、将来課題として管理する
